# ICICLE service templates

Shared Dockerfiles and GitHub Actions workflows for building and deploying Python services, Node backends, and static frontends.

Start with the [shared setup](https://github.com/ICICLE-ai/cicd-templates/wiki/Quick-start), then follow your runtime guide:

- [Python services](https://github.com/ICICLE-ai/cicd-templates/wiki/Python)
- [Node backends](https://github.com/ICICLE-ai/cicd-templates/wiki/Node-backend)
- [Static frontends](https://github.com/ICICLE-ai/cicd-templates/wiki/Static-frontends)
